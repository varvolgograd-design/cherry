# Cherry — лендинг кофейни

Концепт-проект. Кафе вымышленное.

## Состав

    index.html      вся вёрстка и стили, 32 КБ
    img/            10 изображений в WebP, 758 КБ

Внешних зависимостей нет, кроме шрифтов Google Fonts (Prata и Golos Text)
и виджета Яндекс.Карт в блоке контактов.

## Как выложить на GitHub Pages

1. Создать репозиторий, например `cherry`.
2. Загрузить `index.html` и папку `img` в корень.
3. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет по адресу `https://<логин>.github.io/cherry/`.

Свой домен подключается там же, в Settings → Pages → Custom domain.
После этого у регистратора нужно прописать A-записи GitHub Pages
и включить в настройках `Enforce HTTPS`.

## Что нужно заменить перед публикацией

- Телефон `+7 (8442) 00-00-00` — сейчас это пустой слот, чтобы случайно
  не указать чей-то настоящий номер. Ищется по строке `78442000000`.
- Ссылки на Telegram и VK в блоке контактов — стоят заглушки `href="#"`.

## Карта

Виджет Яндекс.Карт работает только на настоящем хостинге или при открытии
файла локально. Внутри предпросмотра артефакта Claude он блокируется
политикой безопасности и показывает пустой прямоугольник.
